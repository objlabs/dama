# 개발 계획

## 0.1 — 로컬 관리 기반 (구현)

- [x] 프로젝트, MCP, 프로젝트별 MCP 연결 데이터 모델
- [x] SQLite 저장, 정합성 검증, 중복 방지, 관리 변경 이력
- [x] 한국어 반응형 대시보드와 등록·삭제·연결 흐름
- [x] 실제 기능과 예정 기능을 UI 및 API에서 구분
- [x] API 통합 테스트와 DB 재시작 후 데이터 유지 검증

편집, 검색, MCP 도구 탐색과 인증·배포 실행은 이 버전에 포함하지 않는다.

## TypeScript 전환 (구현)

- [x] 서버·브라우저·테스트·개발 도구를 TypeScript로 전환
- [x] 공통 모델 타입과 서버/브라우저 분리 strict 검사
- [x] dist 빌드, 정적 자산 복사, 개발 모드 재컴파일·재시작
- [x] 기존 데이터베이스 스키마와 API 형식 유지

## 모노레포·언어별 배포 설정 (구현)

- [x] 프로젝트별 여러 서비스와 Python·Rust·TypeScript 설정
- [x] Dockerfile, 빌드 컨텍스트, 내부 포트, 상태 확인, 서비스별 UUID 하위 경로
- [x] 서비스 등록·편집·삭제 및 배포 계획 미리보기
- [x] MCP 제공 서비스 참조 및 기존 인증서 경로 재사용
- [x] 기존 데이터 보존 마이그레이션과 회귀 테스트
- [x] 세 언어의 최소 Docker 예제

변경 감지 glob은 저장한다. 커밋 SHA로 등록한 작업은 배포 워커에서 실행한다.

## 0.2 — 운영 접속 및 기존 서버 조회

- 소유자 초기 설정과 인증 세션, 비밀 저장, 명시적 스키마 마이그레이션
- 서버 실행 에이전트의 신원과 최소 권한 명령 API
- Docker 및 Nginx 읽기 전용 현황, 기존 프로젝트 가져오기 미리보기
- 프로젝트/MCP 정보 편집

완료 기준: 기존 서버의 앱을 선택해서 등록할 수 있고 기존 컨테이너·Nginx 설정은 변경되지 않는다. 로그인하지 않은 요청은 차단되며 재시작 후에도 설정이 유지된다.

## 0.3 — 단일 서버 배포

- [x] 커밋 SHA 기반 수동 빌드 작업 등록·취소와 SQLite 대기열
- GitHub 웹훅 서명·재전송 검증과 자동 작업 등록
- [x] 고정 커밋 체크아웃, Docker 빌드 및 실행, 상태 확인
- [x] 배포 작업 한 건씩 실행, Nginx 검증·전환 및 실패 시 복원
- 빌드 서버별 동시 작업 한도 설정과 빌드 의존성을 반영한 작업 실행
- 격리 빌드, 이미지·커밋·설정 버전 기록
- 상태 확인, 프로젝트 단위 잠금, Nginx 검증·전환·복구
- 배포/실행 로그, 이전 이미지로 롤백, SSL 발급·갱신

완료 기준: 실제 테스트 서버에서 정상 배포, 빌드 실패, 상태 확인 실패, 잘못된 Nginx 설정, 동시 push, 컨트롤 플레인 재시작과 롤백을 검증한다. 기존 앱의 가용성과 데이터가 보존되어야 한다.

동시성 검증은 한도 1에서 두 서비스 빌드가 순서대로 실행되고, 한도 2에서 독립 빌드 두 개가 겹쳐 실행되며, 의존하는 빌드는 선행 작업이 성공할 때까지 기다리는지 확인한다.

## 0.4 — MCP 사용 가능 상태까지

- 연결 협상·기능 탐색·도구 조회·연결 상태 기록
- 인증 참조 해석, OAuth 연결 및 만료·해제 처리
- 프로젝트별 인증 바인딩과 도구 허용 목록
- 제한된 실행 테스트, 감사 기록, 승인 정책 집행

완료 기준: 직접 배포한 MCP와 외부 MCP에 연결하고 도구를 조회할 수 있다. 타임아웃·인증 만료·잘못된 프로토콜·허용되지 않은 네트워크·미허용 도구가 명확하게 처리된다.

## 0.5 — AI 운영 분석

- 로컬 모델 및 GPT/Claude 제공자 어댑터
- 에이전트별 MCP 연결, 로그·변경·스캔 결과 조회
- 외부 전송 마스킹과 출처가 있는 분석
- 이후 구체적 승인에 묶인 재시작·롤백

완료 기준: 최근 배포와 오류 로그를 연결해 근거를 제시하고, 로그 내 악성 지시나 MCP 설명이 권한을 늘리지 못한다. 승인받지 않은 변경은 실행하지 않는다.

## 후속 확장

stdio 격리 실행기, 통합 MCP 게이트웨이, 여러 서버, 팀별 권한, 관리형 서비스는 앞선 운영 흐름이 검증된 후 진행한다.
